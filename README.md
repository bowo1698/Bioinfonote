# Bioinfonote

Source for **Bioinformatic Notes** — a Bahasa Indonesia learning resource for
bioinformatics with an aquaculture focus, by Agus Wibowo.

Built with [Quarto](https://quarto.org). Published to GitHub Pages:
<https://bowo1698.github.io/Bioinfonote/>

## Local development

```bash
quarto preview   # live preview
quarto render    # build into _site/
```

Content lives in `docs/*.qmd`; the home page is `index.qmd`; site config is `_quarto.yml`.
